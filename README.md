# Codigos-ATC-ANMAT
Dataset completo de la clasificación ATC (Anatomical Therapeutic Chemical) de medicamentos, extraído de la página oficial de la ANMAT (Argentina). Incluye códigos jerárquicos (niveles 1 a 5) y descripciones en español. Ideal para sistemas de información farmacológica, buscadores y apps de salud. Datos en CSV y JSON
